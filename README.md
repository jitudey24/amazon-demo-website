# Amazon Demo Website

A front-end e-commerce homepage practice project inspired by the layout of a large online marketplace. It uses a navigation area, delivery information, and product-shopping interface elements.

## Features
- Marketplace-style navigation bar
- Delivery location area
- E-commerce homepage layout
- Font Awesome icons
- Custom styling with CSS

## Technologies
- HTML5
- CSS3
- Font Awesome

## Run Locally
1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

## Project Purpose
This project is for practicing webpage layout, navigation design, CSS styling, and recreating a familiar e-commerce interface. It is an independent learning project and is not affiliated with Amazon.
